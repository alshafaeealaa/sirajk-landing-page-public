# Sirajk – landing page

Live: https://alshafaeealaa.github.io/sirajk-landing-page-public/

Hebrew landing page for Sirajk, the smart municipal call-center platform by Siraj Technologies.

- `index.html`: the page, with fonts and images inlined
- `film.mp4`: the explainer video (480p, Hebrew narration and burned-in subtitles)
- `poster.jpg`: video poster and link-preview image

The "בקשת הדגמה" form posts to `https://sirajk.sirajtechnologies.com/api/contact`.
The site is a build output: edit and rebuild it from the private `sirajk-landing-page` repo (`landing/`).
